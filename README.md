# Tajawul
Tajawul is an AI-powered tourism platform designed to help travelers discover and explore destinations across the Arab world. The platform combines personalized trip planning, destination discovery, cultural assistance, real-time Arabic dialect translation, and social features into one integrated travel experience.

The system includes an AI recommendation engine for destinations and trips, RafiQ — an intelligent cultural tourism chatbot powered by Retrieval-Augmented Generation (RAG), Arabic dialect machine translation, destination and place exploration, reviews and wishlists, personalized user experiences, traveler social networking, and dedicated features for tourism businesses and place owners.

Tajawul was developed as a full-stack graduation project with a focus on applying Artificial Intelligence, Machine Learning, Natural Language Processing, Data Science, and modern software engineering to real-world tourism challenges.
